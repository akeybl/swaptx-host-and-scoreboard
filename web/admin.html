Team colour → team name

The guns only know four colours. Name the teams and the wall says "SHARKS WIN" instead of "RED TEAM WINS". Leave blank to use the colour.

Gun number → player name

Each gun has a persistent player number (set with the reload button, spoken aloud at power-on). Names show on the wall. Team is learned from the radio; set an override only if the wall never shows the right color.

#NameTeamRadioStats

Host mode

Makes the dongle the admin headset: it takes the host address, acknowledges the guns, and sends the lobby, start and game-over beacons. The settings and the start / end buttons then also appear on the wall.

0 = no target

Current game

These only change what the wall shows. The scoreboard is a passive listener: it never sends anything to the guns. Use them when the dongle missed the host's start or end beacon.

Display rules

The host's objective settings (first to 25, 5-minute game, …) are not broadcast on the radio, so tell the wall what you agreed on. Countdowns and "first to N" progress use these. The radio beacon only distinguishes Team Battle (0) and Battle Royale (1); pick Free for All here when that is what the guns are playing. When the guns' own 10-minute timer is on and no game-over beacon arrives, the wall ends the game itself after the grace period if nobody has scored since time ran out.

Dongle

SWAPTX gear uses ESP-NOW's default channel 1. The sniffer auto-scans after 2 minutes of silence and locks when it hears traffic. Commands only configure the dongle; it never transmits.
